---
name: paper-view-canvas
description: Draw editable SVG diagrams in layers on Paper View Board, or generate raster images.
---

Connect through the Paper View website OAuth page at `https://ipaperview.com` before calling paid tools. Use `list_image_models` to check model and image-size support. Use `quote_image` to report the current Credit cost before a requested generation. Submit with `submit_image`, retaining the returned `job_id` and a stable `client_request_id` for retries. Pass the returned `session_id` on each follow-up change to keep results on the same canvas; omit it only for a new canvas. Use `list_image_jobs` to recover a lost session ID. Poll `get_image_job` until completed or failed. Open the first completed job's `board_url` in WorkBuddy's browser panel if available, or provide a clickable link. Use `open_canvas` only to recover a session's compact board URL. For follow-up jobs, keep the same panel open and let the canvas refresh automatically; do not reopen the URL. The generated raster image can be arranged with SVG elements in the board; do not claim the image pixels are vectors. Never place tokens in tool arguments or chat text.

For a vector diagram, call `start_drawing`, plan its visual layers, and submit one complete SVG layer at a time with `draw_svg_layer`. Keep a common numeric `viewBox`, pass the SVG text rather than a local file path, and reuse the returned `session_id`. Use a stable UUID `client_request_id` for retries. `inspect_drawing` lists current layers and their revisions. Before revising a layer, call `get_svg_layer` and then `update_svg_layer` with its `artifact_ref`, current `base_revision`, revised SVG text, and a new request ID. Reinspect after any version conflict. SVG layers may use shapes, paths, groups, text, gradients and local markers; scripts, CSS stylesheets, external references, embedded images and `foreignObject` are rejected. Each layer is limited to 512 KiB. Open the canvas once and let it sync subsequent layers. The user can edit SVG elements in Board; manual changes to a layer block automatic replacement. SVG layer tools do not consume image-generation Credits.
